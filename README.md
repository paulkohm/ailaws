# Homepage for Artificial Intelligence Law, a Casebook by Margot Kaminski, Paul Ohm, and Andrew Selbst

This repository contains the files for the website https://aila.ws, describing the casebook "Artificial Intelligence Law", first available in Fall 2026 under the Foundation Press University Casebook imprint.

The files are source files for the [Hugo static site generator](https://gohugo.io/). It is hosted in a Cloudflare instance.

[Paul Ohm](https://paulohm.com) is the principal maintainer of this site.
